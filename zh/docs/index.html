快速开始

安装 curl -fsSL gomodvanityurls.com/install.sh | bash 也可以从 最新版本 下载二进制文件。 添加 vanity URL 使用 gomod.io（默认域名，无需配置） $ gvu add gomod.io/private-module https://github.com/yourorg/private-module.git ✔ Route created successfully! ═══════════════════════════════════════════════════════════ ┃ Route ID: m_abc123 ┃ Vanity Path: gomod.io/private-module ┃ Target Repo: https://github.com/yourorg/private-module.git ┃ Quota: 1 / 5 used ═══════════════════════════════════════════════════════════ 系统会自动创建匿名账户，无需注册。 使用自定义域名（需要 Verified 账户） # 第一步：先创建一条路由（同时自动创建匿名账户） gvu add gomod.io/your-module https://github.com/yourorg/your-module.git # 第二步：绑定邮箱，升级为 Verified 账户 gvu auth bind user@example.com # 输入发送到邮箱的 6 位验证码 # 第三步：添加自定义域名路由 gvu add go.yourcompany.com/private-module https://github.com/yourorg/private-module.git # 配置 DNS 解析 # go.yourcompany.com CNAME gomodvanityurls.com 配置 Go 环境 告诉 Go 工具链直接解析你的 vanity 路径： ...

自定义域名

Verified 和 Pro 用户可以使用自己的域名作为 vanity URL 前缀。 前提条件 Verified 或 Pro 账户（运行 gvu auth bind <email> 即可升级） 一个你拥有 DNS 管理权限的域名 配置步骤 1. 添加自定义域名路由 gvu add go.yourcompany.com/private-module https://github.com/yourorg/private-module.git 2. 配置 DNS 通过 CNAME 将你的域名指向服务： go.yourcompany.com CNAME gomodvanityurls.com 3. 等待 TLS 证书签发 TLS 证书会自动签发。CLI 在创建路由后会探测该路由，如果 TLS 仍在签发中会给出提示。 4. 开始使用 import "go.yourcompany.com/private-module" 配额 套餐 自定义域名路由数 Anonymous 0 Verified 1 Pro 50 使用技巧 建议使用子域名，如 go.yourcompany.com 或 pkg.yourcompany.com 自定义域名路由不受短路径限制 可以在同一账户中同时使用 gomod.io 和自定义域名路由

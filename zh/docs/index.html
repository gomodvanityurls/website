快速开始

自定义域名

Verified 和 Pro 用户可以使用自己的域名作为 vanity URL 前缀。 前提条件 Verified 或 Pro 账户（运行 gvu auth bind <email> 即可升级） 一个你拥有 DNS 管理权限的域名 已安装 gvu CLI — 参见 快速开始（Windows：使用 WSL/WSL2 或下载 .exe） 配置步骤 1. 添加自定义域名路由 gvu add go.yourcompany.com/private-module https://github.com/yourorg/private-module.git 2. 配置 DNS 通过 CNAME 将你的域名指向服务： go.yourcompany.com CNAME gomodvanityurls.com 3. 等待 TLS 证书签发 TLS 证书会自动签发。CLI 在创建路由后会探测该路由，如果 TLS 仍在签发中会给出提示。 4. 开始使用 import "go.yourcompany.com/private-module" 配额 套餐 自定义域名路由数 Anonymous 0 Verified 1 Pro 50 使用技巧 建议使用子域名，如 go.yourcompany.com 或 pkg.yourcompany.com 自定义域名路由不受短路径限制 可以在同一账户中同时使用 gomod.io 和自定义域名路由 --subdir 也适用于自定义域名： gvu add go.mycompany.com/module-a https://github.com/myorg/monorepo.git --subdir go/module-a

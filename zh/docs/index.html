自定义域名

Verified 和 Pro 用户可以使用自己的域名作为 vanity URL 前缀。 前提条件 Verified 或 Pro 账户（运行 gvu auth bind <email> 即可升级） 一个你拥有 DNS 管理权限的域名 配置步骤 1. 添加自定义域名路由 gvu add go.yourcompany.com/private-module https://github.com/yourorg/private-module.git 2. 配置 DNS 通过 CNAME 将你的域名指向服务： go.yourcompany.com CNAME gomodvanityurls.com 3. 等待 TLS 证书签发 服务会通过 Caddy On-Demand TLS 自动签发 TLS 证书。CLI 在创建路由后会探测该路由，如果 TLS 仍在签发中会给出提示。 4. 开始使用 import "go.yourcompany.com/private-module" 工作原理 开发者运行: go get go.yourcompany.com/private-module │ ▼ DNS CNAME → gomodvanityurls.com │ ▼ Caddy 接收 HTTPS 请求 │ ▼ On-Demand TLS: 询问 gvud "该域名是否有效？" │ ▼ gvud 检查: 布隆过滤器 → 缓存 → SQLite │ ▼ 返回 go-import meta 标签 → Go 工具链从 Git 仓库拉取代码 配额 套餐 自定义域名路由数 Anonymous 0 Verified 1 Pro 50 使用技巧 建议使用子域名，如 go.yourcompany.com 或 pkg.yourcompany.com 自定义域名路由不受短路径限制 可以在同一账户中同时使用 gomod.io 和自定义域名路由

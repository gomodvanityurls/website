快速开始

5 分钟内完成 Go vanity URL 的配置与使用
Tony Bai

安装#

curl -fsSL gomodvanityurls.com/install.sh | bash

也可以从 最新版本 下载二进制文件。

添加 vanity URL#

使用 gomod.io（默认域名，无需配置）#

$ gvu add gomod.io/mylib https://github.com/yourorg/mylib.git

✔ Route created successfully!
═══════════════════════════════════════════════════════════
┃ Route ID:     m_abc123
┃ Vanity Path:  gomod.io/mylib
┃ Target Repo:  https://github.com/yourorg/mylib.git
┃ Quota:        1 / 5 used
═══════════════════════════════════════════════════════════

系统会自动创建匿名账户，无需注册。

使用自定义域名（需要 Verified 账户）#

# 首先绑定邮箱，升级为 Verified 账户
gvu auth bind user@example.com
# 输入发送到邮箱的 6 位验证码

# 然后添加自定义域名路由
gvu add go.yourcompany.com/mylib https://github.com/yourorg/mylib.git

# 配置 DNS 解析
# go.yourcompany.com  CNAME  gomodvanityurls.com

配置 Go 环境#

告诉 Go 工具链直接解析你的 vanity 路径：

export GOPRIVATE=gomod.io
# 如果有自定义域名，也加上：
export GOPRIVATE=gomod.io,go.yourcompany.com

将上述命令添加到 ~/.bashrc 或 ~/.zshrc 中以持久化配置。

使用#

import "gomod.io/mylib"
import "go.yourcompany.com/mylib"

Go 工具链会自动将 vanity 路径解析到你的 Git 仓库。如果将来迁移代码仓库，用户的导入路径保持不变。

管理路由#

# 列出你的路由
gvu list

# 删除路由
gvu remove m_abc123

# 批量删除
gvu remove m_abc123 m_def456 -y

# 查看账户信息
gvu auth whoami

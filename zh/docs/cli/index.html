路由管理#

命令说明
gvu add <vanity-path> <repo-url>添加新的 vanity URL 路由
gvu list列出所有已注册的路由
gvu remove <route-id> [...]删除一个或多个路由

gvu add#

托管平台会根据仓库 URL 自动识别。

# gomod.io 路由（默认域名，所有用户可用）
gvu add gomod.io/private-module https://github.com/myorg/private-module.git
gvu add gomod.io/private-module https://gitlab.com/myorg/private-module.git
gvu add gomod.io/private-module git@github.com:myorg/private-module.git

# 自定义域名路由（仅 Verified/Pro 用户可用）
gvu add go.mycompany.com/private-module https://github.com/myorg/private-module.git
gvu add go.mycompany.com/api   ssh://git@gitlab.example.com:2222/group/api.git

gvu remove#

支持批量删除：

gvu remove m_abc123                    # 单个删除
gvu remove m_abc123 m_def456           # 多个删除
gvu remove m_abc123 m_def456 -y        # 跳过确认

认证#

命令说明
gvu auth signup创建匿名账户
gvu auth bind <email>绑定邮箱，升级为 Verified
gvu auth login <email>在新设备上通过邮箱验证码登录
gvu auth logout清除本地凭证
gvu auth whoami显示当前账户信息和配额

其他命令#

命令说明
gvu donate显示捐赠二维码
gvu issue提交 GitHub Issue
gvu --version显示版本号

全局参数#

参数简写说明
--json-j结构化 JSON 输出
--yes-y跳过确认提示
--version-v显示版本号

JSON 输出#

所有命令都支持 --json：

$ gvu list --json
{
  "status": "success",
  "data": {
    "routes": [
      {
        "id": "m_abc123",
        "vanity_path": "gomod.io/private-module",
        "target_repo": "https://github.com/myorg/private-module.git",
        "repo_type": "github"
      }
    ]
  }
}

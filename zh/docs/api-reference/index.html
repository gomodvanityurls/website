API 参考

gomodvanityurls 服务端 REST API 端点
Tony Bai | 语言:
  • En

Base URL: https://api.gomodvanityurls.com

认证#

方法端点说明
POST/api/v1/auth/otp请求 OTP 验证码
POST/api/v1/auth/token验证 OTP 并获取访问令牌
POST/api/v1/auth/signup创建匿名账户
POST/api/v1/auth/logout使当前访问令牌失效

路由管理#

需要 Authorization: Bearer sk_live_... 请求头。

方法端点说明
POST/api/v1/routes创建 vanity URL 路由
GET/api/v1/routes列出你的路由
DELETE/api/v1/routes/{id}删除路由
POST/api/v1/routes/check检查路径是否可用

域名验证#

方法端点说明
GET/api/v1/domains/check?domain=...Caddy On-Demand TLS 域名检查

基础设施#

方法端点说明
GET/health健康检查
GET/?go-get=1Go vanity URL 解析

访问令牌#

  • 前缀：sk_live_
  • 有效期：90 天
  • 自动刷新：每次成功的 API 调用都会刷新令牌

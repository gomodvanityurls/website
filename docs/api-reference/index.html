API Reference

REST API endpoints for the gomodvanityurls server
Tony Bai

Base URL: https://api.gomodvanityurls.com

Authentication#

MethodEndpointDescription
POST/api/v1/auth/otpRequest OTP verification code
POST/api/v1/auth/tokenVerify OTP and receive access token
POST/api/v1/auth/signupCreate an anonymous account
POST/api/v1/auth/logoutInvalidate current access token

Route Management#

Requires Authorization: Bearer sk_live_... header.

MethodEndpointDescription
POST/api/v1/routesCreate a vanity URL route
GET/api/v1/routesList your routes
DELETE/api/v1/routes/{id}Delete a route
POST/api/v1/routes/checkCheck path availability

Domain Validation#

MethodEndpointDescription
GET/api/v1/domains/check?domain=...Caddy On-Demand TLS domain check

Infrastructure#

MethodEndpointDescription
GET/healthHealth check
GET/?go-get=1Go vanity URL resolution

Access tokens#

  • Prefix: sk_live_
  • Expiry: 90 days
  • Auto-refresh: tokens are refreshed on each successful API call

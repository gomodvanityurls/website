Custom Domains

Use your own domain as a Go vanity URL prefix
Tony Bai

Verified and Pro users can use their own domain as the vanity URL prefix.

Prerequisites#

  • A Verified or Pro account (run gvu auth bind <email> to upgrade)
  • A domain you control with DNS management access

Setup#

1. Add a custom domain route#

gvu add go.yourcompany.com/mylib https://github.com/yourorg/mylib.git

2. Configure DNS#

Point your domain to the service via CNAME:

go.yourcompany.com  CNAME  gomodvanityurls.com

3. Wait for TLS#

The service automatically provisions TLS certificates via Caddy On-Demand TLS. The CLI probes the route after creation and warns you if TLS is still provisioning.

4. Use it#

import "go.yourcompany.com/mylib"

How it works#

Developer runs: go get go.yourcompany.com/mylib
                          │
                          ▼
                DNS CNAME → gomodvanityurls.com
                          │
                          ▼
            Caddy receives HTTPS request
                          │
                          ▼
        On-Demand TLS: ask gvud "is this domain valid?"
                          │
                          ▼
            gvud checks: Bloom Filter → Cache → SQLite
                          │
                          ▼
            Returns go-import meta tag → Go toolchain fetches from Git repo

Tips#

  • Use a subdomain like go.yourcompany.com or pkg.yourcompany.com
  • Custom domain routes are exempt from the short path restriction
  • You can mix gomod.io and custom domain routes in the same account

Install & use in 30 seconds#

# 1. Install the CLI
curl -fsSL gomodvanityurls.com/install.sh | bash

# 2. Add a vanity URL (anonymous account created automatically)
gvu add gomod.io/mylib https://github.com/yourorg/mylib.git

# 3. Use it
import "gomod.io/mylib"

That’s it. The Go toolchain resolves the vanity path to your Git repo automatically.

Features#

  • One-command setup — install CLI, add route, done
  • Auto-detected platforms — GitHub, GitLab, Bitbucket, Codeberg, self-hosted
  • Custom domains — use your own domain with automatic TLS certificates
  • Passwordless auth — email OTP, no password to manage
  • Lightweight — single binary, SQLite storage, no dependencies

Clean vanity URLs for Go modules

Replace long GitHub/GitLab import paths with short, stable vanity URLs. One command to set up, works with any Git host.

Custom Domains

Verified and Pro users can use their own domain as the vanity URL prefix. Prerequisites A Verified or Pro account (run gvu auth bind <email> to upgrade) A domain you control with DNS management access Setup 1. Add a custom domain route gvu add go.yourcompany.com/mylib https://github.com/yourorg/mylib.git 2. Configure DNS Point your domain to the service via CNAME: go.yourcompany.com CNAME gomodvanityurls.com 3. Wait for TLS The service automatically provisions TLS certificates via Caddy On-Demand TLS. The CLI probes the route after creation and warns you if TLS is still provisioning. ...
